# Manaf Saidi — Academic website

Personal research profile for PhD applications.

Website: https://manafsaidi.github.io/

## Structure
- `index.html` — About, research directions, selected work, academic background, and contact
- `styles.css` — Responsive presentation
- `script.js` — Mobile navigation and copyright year
- `assets/favicon.svg` — Website icon

## Publishing with GitHub Pages

In this repository, open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select branch **main**, folder **/(root)**, and save. The site will publish at the URL above once GitHub Pages finishes deployment.

## Updating your profile

Edit `index.html` to update biography, publication statuses, and conference information. Add your preferred public email, CV, and verified scholarly links when ready.

This website does not yet include a professional portrait or downloadable CV. Check all factual details before using the URL in applications.
